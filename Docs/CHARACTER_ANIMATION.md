## 현재 기준 — 2026-09-28

## 현재 에셋과 확인 방법

원화·프레임 에셋은 `Assets/Resources/Online/PixelV1/`에 있다. 정확한 생성 프롬프트·원본 식별자·실제 해상도는 [아트 기록](Art/PixelMotionV1.md)을 따른다.

- 성별별 `Actions.png`: 대기 2장, 착지 웅크림, 상승·정점·하강 3장.
- 성별별 `Walk.png`: 걷기 8장.
- 성별별 `Arms.png`: 긴 총 5방향+대기, 권총 5방향+대기, 총 12장.
- `Weapons.png`, `Handguns.png`: 총기 6계열과 근접무기, 각 3등급으로 사용 외형 21개.
- `MaleBody/FemaleBody.asset`: 런타임 16칸. 대기 2장을 4칸에 반복 등록하고 걷기 8장·착지/공중 4장을 연결한다. 서로 다른 몸체 그림은 성별별 14장이다.
- `MaleArms/FemaleArms.asset`: 양팔 그림과 무기 부착 좌표 12개.

게임 프리팹은 `Assets/Resources/Online/Rigs/GunnerMale.prefab`, `GunnerFemale.prefab`이다. 로그인 초상화는 기존 `GunnerMale.png`, `GunnerFemale.png`를 사용한다. 배경·NPC·로그인 UI 전체를 새 화풍으로 바꾼 작업은 아니다.

Unity 메뉴 **MiniWar > Characters > Motion preview**에서 서버 없이 확인한다.

- Male / Female: 남녀 선택.
- Idle / Walk / Jump: 대기, 걷기, 점프·착지. Animate를 끄면 위상을 직접 조절한다.
- Weapon / Tier: 피스톨·리볼버·기관단총·샷건·소총·저격총·근접무기, 각 3등급.
- Aim angle: 위 +90°, 윗사선 +45°, 앞 0°, 아랫사선 -45°, 아래 -90°. Face left로 반전한다.
- Fire recoil preview: 통짜 팔과 무기를 짧게 함께 움직이는 반동.
- Part colors: 몸체와 양팔 레이어 구성을 확인한다.

별도 미리보기 씬을 사용하므로 열린 게임 씬을 바꾸지 않는다. **Pixel style study** 메뉴는 화풍을 확정했던 남캐 대기 한 자세의 과거 기준 샘플이다. 현재 게임 전체 동작은 **Motion preview**로 확인한다.

## 가져오기와 연결

`PixelCharacterTools.cs`가 원화 알파 영역을 찾아 Unity 스프라이트를 등록한다. 원화 픽셀 자체는 프로그램으로 다시 그리거나 분리 합성하지 않는다. Point 필터·압축 없음·밉맵 없음, 프레임별 어깨 좌표와 발 기준점으로 연결한다. 서 있는 기준 키는 2.75월드 단위다. 공중에서 무릎을 접은 그림을 그 키로 늘리지 않는다. 생성기에 요청한 정확한 논리 픽셀 수나 색상 수는 보장된 측정치가 아니다.

`CharacterRig.cs`는 몸체 프레임의 어깨 좌표에 양팔 그림을 놓고, 팔에 저장된 손잡이 좌표에 장착 무기를 붙인다. 얼굴·목·허리·다리 사이에는 별도 관절이 없다. 남녀 프리팹은 온라인 플레이에도 그대로 사용한다.

**Build part sprites and rigs** 메뉴는 현재 도트 시트에서 프레임 에셋과 프리팹을 재생성한다. 같은 이름의 스프라이트 GUID를 유지한다. 수동으로 바꾼 생성 프리팹/좌표는 먼저 복제하거나 생성 코드에 반영해야 한다. `CharacterBodyTools`와 `CharacterArmTools`는 이전 시트용 보조 코드이며 현재 빌드의 원화 등록은 `PixelCharacterTools`가 맡는다.

## 온라인 연습 사격

- 우클릭 조준, 좌클릭 사격. 좌클릭 자체로도 조준한다. 채팅·장비 창·UI 위 클릭 중에는 발사하지 않는다.
- 팔과 총 그림은 5방향, 발사각은 발사 순간 실제 마우스 방향이다. 이후 커서를 따라 휘지 않는다.
- 서버가 장착 무기·입력 순번·발사 간격을 확인해 같은 채널에 발사각과 shot ID를 전송한다.
- 클라이언트는 현재 그림 총구에서 탄 흔적과 반동을 표시한다. 서버의 기준 위치는 캐릭터 어깨이며, 지금 탄환은 충돌/피해 권한 없는 시각 효과다.
- 마을에서는 탄약·재화 소모와 피해가 없다. 근접무기는 탄을 발사하지 않는다. 샷건은 실제 발사각을 중심으로 5개 탄을 대칭 배치한다.
- 0.5초 이상 입력이 끊기거나 채널을 바꾸면 발사를 멈춘다. 채널 이동/로그아웃 때 탄 효과를 지운다.
- 통신 버전 3, 기존 계정 저장 형식과 무기 ID 유지. 이번 아트 전환은 프로토콜을 바꾸지 않았다.
