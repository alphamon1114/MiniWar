# MiniWar — 왕국 탈환전

2026-09-23 사용자와 확정한 최신 기획. 초기 Notion 기획/Assets/Scripts/README.md보다 우선한다.

## 목표
- 1인 학원 프로젝트, 약 3~4일 제작 목표. Windows 클라이언트, 학원 내부 LAN.
- 학원 Windows PC에서 서버를 직접 실행한다.
- 닉네임/비밀번호로 계정 등록·로그인. 계정마다 진행·재화·개별 무기를 영구 저장한다.
- 마을 약 20~30명. 필요시 채널 분리. 마을 채팅과 파티 채팅.
- 파티 일반 던전 4개, 레이드 1개, 마을 1:1 거래, 레이드 클리어 시간 랭킹.

## 세계관과 아트
총기를 사용하는 주인공 왕국을 마법 왕국이 흑마법으로 침공했다. 주인공들은 점령당한 고향을 탈환한다. 아라곤은 점령군의 왕이다. 마을은 생존자와 탈환군의 준비 거점이다.

던파풍 판타지 도트. 기존 NPC 스프라이트는 보존하며 나머지 배경·주인공·적·UI는 개편한다. 좌우 이동·점프·마우스 조준과 총기·근접무기를 사용한다.

### 캐릭터·총기 최신 결정
- 생성 시 남성/여성 선택. 선택한 외형은 계정에 저장하고 다른 플레이어에게 동기화한다.
- 남성: 생성된 갈색 머리·남색 코트 디자인 유지. 여성: 첨부한 금발·검은 베레모·검은 군복·금색 장식·흰 장갑 디자인 참고.
- 총기는 **샷건 / 소총 / 기관단총 / 저격총 / 피스톨 / 리볼버** 6종이다. 권총 안에서 글록 같은 피스톨과 회전 탄창의 리볼버를 독립된 종류로 구분한다. 미사일 제외. 탄약 없이 쓰는 근접무기는 별도 계열이다.
- 피스톨과 리볼버는 각각 1~3등급을 가지며, 등급 상승으로 종류가 바뀌지 않는다. 두 종류 모두 얼굴 옆으로 세워 드는 권총 준비 자세를 쓴다. 공격력·연사·장탄수 차이는 아직 미정이다.
- 프로토콜 ID: 피스톨=0, 기관단총=1, 샷건=2, 소총=3, 저격총=4, 근접=5, 리볼버=6. 기존 저장 ID는 유지한다. 통신 버전은 2이며 클라이언트와 서버를 함께 갱신한다. 이전 Claude 초안의 대전차/수류탄 ID와 혼용 금지.
- 몸과 총기 스프라이트를 분리한다. 장착한 개별 무기의 계열·등급에 맞는 실제 무기를 표시한다.
- 권총 대기 자세: 사용자의 스케치처럼 팔꿈치를 굽혀 총을 얼굴 옆으로 세운다. 조준 중에는 총구를 마우스 방향으로 향한다.
- 현재 외형 시트는 대기·권총 준비 자세 초안이다. 달리기·발사·재장전 등 전투 애니메이션은 후속 작업이다.

|순서|이름|배경 / 일반 적|보스|
|---|---|---|---|
|1|성문 외곽|무너지는 성벽 밖 / 순찰대원|성문 고정 대포|

|3|왕궁진입로|불길한 왕궁 / 흑마법사·경비병|아라곤: 대검, 범위 마법|
|4|지하신전|흑마법으로 오염된 신전 / 흑마법사·경비병|검은 수정: 고정형, 광역기, 파훼로 중단 가능한 즉사기|

## 전투 규칙
- 일반 던전 1~4명. 입장 인원별 개인 공격력: 4명 ×1, 3명 ×1.25, 2명 ×1.8, 1명 ×3.3.
- 레이드 4~6명. 인원 공격력 보너스 없음.
- 공격력 보너스는 입장 인원으로 고정한다(제안 기본안).
- 개인당 인던 1회에 한 번 제자리 부활, 체력 100%, 짧은 무적. 두 번째 사망 이후 팀원 관전.
- 전원 최종 사망 시 실패 후 마을 귀환.
- 탄약·재화 부족은 강제 탈락이 아니다. 근접무기로 계속 싸울 수 있어야 한다.
- 큰 범위기는 화면 경고와 바닥 전조. 즉사기는 패턴 파훼로 중단 가능하며 솔로 일반 던전에서도 파훼 가능해야 한다.

## 보상·거래·성장
- Claude outputs의 성장 설계를 서버 판정으로 이식하되 무기 분류는 최신 결정을 따른다: 총기 6종과 별도 근접무기, 각각 3등급, 개별 인스턴스, +15 확률 강화, 하락/파괴, 3정 합성, 분해/부적/방지권.
- 일반 공용 카드 4장, 레이드 공용 카드 8장. 모두 같은 화면을 보고 각자 서로 다른 카드 한 장을 선택한다.
- 보상은 서버가 미리 결정하고 선택 완료 시 한 번만 지급한다. 미선택 보상은 공개하지 않는다.
- 남은 카드는 선택 종료 후 불타 사라지는 연출.
- 시간 초과·접속 종료 시 자동 배정/지급은 기본 제안이며 별도 사용자 변경이 없으면 적용한다.
- 무기와 재화는 영구 보유, 멀티에서 사용 가능. 강화 무기도 1:1 거래 가능. 경매장 제외.
- 마을에서 양측이 물품을 확인하고 최종 승인한다. 제안 변경 시 양측 승인을 초기화한다.
- 서버가 전투 시작부터 보스 사망까지 측정해 레이드 참여자 전원 이름과 시간을 저장한다.

## 구현 원칙
서버가 이동 한계·공격·피해·재화·아이템·강화·카드 지급·거래·랭킹을 검증한다. 클라이언트가 보상/수치를 확정하지 않는다. 거래 양측 저장은 하나의 트랜잭션이어야 한다. 비밀번호 평문 저장 금지.
